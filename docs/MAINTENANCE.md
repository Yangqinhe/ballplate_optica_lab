# 维护与发布边界

## 本次整理

目标仓库为 `Yangqinhe/ballplate_optica_lab`，使用独立 Git 目录，不改变原 `mujoco-project-rl` 的 remote，不提交原仓库中的无关修改。

本次只上传核心代码、源码追溯清单、MuJoCo XML 与说明。此前为发布准备的数据摘要和模型副本已移出本仓库，保存在实验机 E111 发布记录下；没有删除原始实验或权重。缓存清理只移动可再生成的 Python/pytest 缓存到可恢复隔离区。

## 代码、数据和权限分离

- `provenance/SOURCE_FILES.json` 记录复制来源和 SHA256；用于追溯，不是实验结果或硬件启动许可。
- `.gitignore` 排除 RAW、图像、训练 checkpoint、SLM/标定数组、日志、SDK、凭据和本机配置。
- 后续补充实验结果应另选数据存储位置；不要直接 `git add -f` 将大数据塞进源码仓库。
- 不提交令牌、相机地址/序列号配置、显示器身份授权、旧会话恢复许可或 SDK 安装包。
- 原始数据、失败实验与已见测试集身份在本地保留；不把代码测试通过写成光路或控制部署通过。

## 后续整理建议

冻结 `snapshots/` 作为本次备份。新功能优先在明确的小模块中开发，逐步用测试替换旧路径依赖；每次只迁移一个责任边界，避免为了代码整洁一次改动正在运行的硬件入口。

本次发布未额外授予第三方 SDK 的再分发权限，也未替项目选择开源许可证。
